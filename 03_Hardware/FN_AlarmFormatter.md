# FN_AlarmFormatter

---

# Purpose

Converts an alarm code into a standardized alarm message.

This function provides a single location for alarm text generation, ensuring consistent alarm descriptions across the PLC, HMI, and AquaFeed Manager.

---

# Function

```iecst
FUNCTION FN_AlarmFormatter : STRING[100]

VAR_INPUT

    AlarmCode : UINT;

END_VAR

CASE AlarmCode OF

    0:
        FN_AlarmFormatter := 'No Alarm';

    1001:
        FN_AlarmFormatter := 'Emergency Stop Activated';

    1002:
        FN_AlarmFormatter := 'Blower Fault';

    1003:
        FN_AlarmFormatter := 'Selector Fault';

    1004:
        FN_AlarmFormatter := 'Dosing Motor Fault';

    1005:
        FN_AlarmFormatter := 'Communication Timeout';

    1006:
        FN_AlarmFormatter := 'Recipe Validation Failed';

    1007:
        FN_AlarmFormatter := 'Selected Line Not Ready';

    ELSE

        FN_AlarmFormatter := 'Unknown Alarm';

END_CASE;
```

---

# Inputs

AlarmCode

Alarm code generated by the PLC.

---

# Output

Returns the corresponding alarm description.

---

# Example

```iecst
AlarmText :=
FN_AlarmFormatter(
    AlarmCode := ActiveAlarm.AlarmCode
);
```

---

# Used By

- FB_AlarmManager
- HMI
- AquaFeed Manager
- Report Manager
- Alarm History

---

# Rules

Every alarm code shall have only one description.

Alarm descriptions shall remain consistent across all software layers.

Unknown alarm codes shall return "Unknown Alarm".

The function shall not modify any global variables.

The function contains no side effects.
