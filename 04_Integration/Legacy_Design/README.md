# Legacy Integration and Edge Design Sources

| Field | Value |
|---|---|
| Status | Legacy / Non-authoritative |
| Owner | Integration / Edge |
| Origin | Former PLC Function Block specifications |

These documents describe platform services rather than deterministic PLC Function Blocks. Their original content and `FB_` names are retained only for traceability.

Implementation contracts must be rewritten under Integration/Edge architecture. No legacy document may directly authorize PLC code.
