# Function

FN_CalculateKgPerPulse

---

# Function

FN_CalculateKgPerPulse

---

# Purpose

Calculates the feed quantity represented by a single encoder pulse or counting pulse during dosing operation.

This function is used for precise feed measurement and calibration of the dosing system.

---

# Inputs

| Name | Type | Description |
|------|------|-------------|
| CalibrationAmount | REAL | Known feed amount used during calibration (kg) |
| PulseCount | DINT | Total pulse count measured during calibration |

---

# Output

| Name | Type | Description |
|------|------|-------------|
| Return | REAL | Feed amount per pulse (kg/pulse) |

---

# Formula

```text
KgPerPulse =
CalibrationAmount /
PulseCount
```

---

# Logic

```text
IF CalibrationAmount <= 0.0 THEN

    Return := 0.0;

ELSIF PulseCount <= 0 THEN

    Return := 0.0;

ELSE

    Return :=
        CalibrationAmount /
        REAL(PulseCount);

END_IF;
```

---

# Rules

- CalibrationAmount shall be greater than zero.
- PulseCount shall be greater than zero.
- Division by zero shall be prevented.
- The returned value represents the feed amount generated by one pulse.
- The function shall execute within a single PLC scan.
- The function shall not modify input parameters.
- No persistent memory shall be used.

---

# Return Value

| Condition | Return |
|-----------|--------|
| Valid calibration | kg/pulse value |
| Invalid calibration amount | 0.0 |
| Invalid pulse count | 0.0 |

---

# Typical Usage

- Dosing motor calibration
- Encoder based feed measurement
- Pulse counter scaling
- Accurate batch feeding
- Feed consumption calculation

# Complexity

Time Complexity

O(1)

Memory Usage

Constant

---

# Notes

This function calculates only the feed amount represented by one pulse.

It does not:

- Count pulses
- Read encoder inputs
- Control dosing motor
- Store calibration data
- Start calibration procedure
- Validate mechanical conditions

These responsibilities belong to the calling Function Block.
