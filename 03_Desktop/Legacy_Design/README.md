# Legacy Desktop Design Sources

| Field | Value |
|---|---|
| Status | Legacy / Non-authoritative |
| Owner | AquaFeed Manager / Desktop |
| Origin | Former PLC Function Block specifications |

These documents were moved out of the PLC tree because they define database, user, reporting, farm-management, inventory, commercial, quality, licensing, or analytics responsibilities.

They are retained as design-input sources only. Their `FB_` names do not imply PLC implementation. New implementation contracts must be created under the appropriate Desktop architecture, domain, application, infrastructure, or test area.

Realtime machine control, safety, IO, active job execution, bounded counters, alarms, and communication snapshots remain PLC responsibilities.
