# NVM AquaFeed Platform

## Line Load Balancer

Document ID : AQ-LLB-047

--------------------------------------------------
Purpose

Distribute missions equally between feeding lines whenever possible.

--------------------------------------------------

Example

Line 1

420 kg Queue

Line 2

110 kg Queue

↓

Suggestion

Move compatible mission to Line 2

--------------------------------------------------

The software shall never move a mission automatically.

Operator approval required.

--------------------------------------------------
