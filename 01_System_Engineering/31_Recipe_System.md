# NVM AquaFeed Platform

## Feed Recipe Management

Document ID : AQ-RCP-031

Version : 1.0

Status : Draft

--------------------------------------------------
1. Purpose
--------------------------------------------------

The Recipe System defines which feed shall be delivered to which fish lot.

Recipes reduce operator errors and standardize feeding.

Recipes are optional.

Operators may bypass recipes if authorized.

--------------------------------------------------
2. Recipe Structure
--------------------------------------------------

Recipe ID

Recipe Name

Feed Type

Feed Diameter

Recommended Fish Weight

Recommended Daily Feed %

Recommended Feeding Rate

Notes

--------------------------------------------------
3. Recipe Assignment
--------------------------------------------------

Recipe

↓

Fish Lot

↓

Mission

Recipe values become default values.

Operator may modify them.

--------------------------------------------------
4. Feed Transition
--------------------------------------------------

Recipe supports feed transition.

Example

2 mm

↓

3 mm

↓

4 mm

↓

6 mm

Transition history shall be recorded.
