# NVM AquaFeed Platform

## Antigravity Development Rules

Document ID : AQ-AG-040

Version : 1.0

--------------------------------------------------
Purpose
--------------------------------------------------

This document defines mandatory rules for AI-assisted software development.

--------------------------------------------------
General Rules
--------------------------------------------------

The AI shall never invent system behavior.

The AI shall follow Engineering Specification documents.

The AI shall not rename existing modules.

The AI shall preserve database compatibility.

The AI shall preserve Modbus compatibility.

The AI shall not remove existing parameters.

The AI shall not modify alarm codes without approval.

--------------------------------------------------
Implementation Order
--------------------------------------------------

1. Database

2. Backend

3. PLC Interface

4. UI

5. Reports

6. Smart Farm

7. Service Tools

--------------------------------------------------
Output Quality
--------------------------------------------------

Every generated module shall include

Source Code

Comments

Error Handling

Logging

Unit Tests

Documentation

--------------------------------------------------
Acceptance
--------------------------------------------------

Generated code shall compile without errors.

Generated code shall follow project architecture.

Generated code shall be maintainable.

--------------------------------------------------

End Of Document
