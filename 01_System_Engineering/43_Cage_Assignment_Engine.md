# NVM AquaFeed Platform

## Cage Assignment Engine

Document ID : AQ-CAG-043

Version : 1.0

--------------------------------------------------
1. Purpose
--------------------------------------------------

A cage is not permanently assigned to one feeding line.

The assignment engine manages cage locations.

--------------------------------------------------
2. Cage Assignment
--------------------------------------------------

Each cage contains

Current Line

Current Selector Eye

Current Feed

Current Fish Lot

--------------------------------------------------
3. Cage Transfer
--------------------------------------------------

Operator selects

Move Cage

↓

New Feeding Line

↓

New Selector Eye

↓

Save

History recorded.

--------------------------------------------------
4. Validation
--------------------------------------------------

Target Eye

must be empty.

Target Line

must exist.

--------------------------------------------------
5. History
--------------------------------------------------

Every transfer

stores

Old Line

Old Eye

New Line

New Eye

Operator

Reason
