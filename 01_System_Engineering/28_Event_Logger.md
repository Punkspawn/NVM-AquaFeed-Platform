# NVM AquaFeed Platform

## Event Logger

Document ID : AQ-EVT-028

Version : 1.0

--------------------------------------------------

Every important action shall be stored.

--------------------------------------------------

Examples

User Login

User Logout

Mission Start

Mission Pause

Mission Resume

Mission Finish

Alarm

Alarm Reset

Parameter Change

Calibration

Maintenance

--------------------------------------------------

Each event stores

Date

Time

User

Machine

Description

Old Value

New Value

--------------------------------------------------

Event history shall never be deleted automatically.

--------------------------------------------------
